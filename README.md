# تحدي الأرقام — Number Match

لعبة أرقام عربية تعمل مباشرة في المتصفح دون تثبيت أو مكتبات خارجية.

## التشغيل
افتح `index.html` أو انشر المستودع عبر GitHub Pages.

## القواعد
- احذف رقمين متساويين أو رقمين مجموعهما 10.
- يمكن أن يكون الاتصال بخط أفقي أو رأسي أو قطري مستقيم، بشرط خلو الخانات بين الرقمين.
- يمكن أيضاً حذف رقمين متتابعين في ترتيب الأرقام المتبقية عند نهاية الصف وبداية الصف التالي.
- كل عملية حذف تمنح 10 نقاط. زر التراجع يعيد آخر حالة.

## النشر
من إعدادات المستودع: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
