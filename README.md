# رحلة الأرقام ✨

لعبة ألغاز عربية RTL تعمل على الويب، ويمكن تحويلها إلى تطبيق Android.

## اللعب
- احذف رقمين متساويين أو رقمين مجموعهما 10.
- يجب أن يكون الطريق بينهما أفقيًا أو رأسيًا أو قطريًا وخاليًا من الأرقام.
- يمكن أيضًا مطابقة رقمين متتاليين في ترتيب الأرقام المتبقية.
- كل مطابقة تمنح 10 نقاط.
- استخدم التلميح والتراجع وإضافة الأرقام عند الحاجة.

## المراحل
30 مرحلة في 3 عوالم، بأهداف متصاعدة وعدد حركات محدود. يُحفظ فتح المراحل والنجوم وأفضل نتيجة محليًا على الجهاز.

## الموقع
انشر من GitHub Pages عبر الفرع main والمجلد /(root).

## إنشاء APK
يبدأ GitHub Actions تلقائيًا عند تحديث ملفات اللعبة، أو يدويًا من تبويب Actions ثم Build Android APK ثم Run workflow.
بعد انتهاء البناء، افتح تشغيل الـ workflow وحمّل Artifact باسم `number-journey-android-apk`.

المشروع يستخدم Capacitor لتغليف ملفات الويب كتطبيق Android. يتطلب البناء المحلي Node.js وAndroid Studio وAndroid SDK.
