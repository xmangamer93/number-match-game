# لعبة الأبقار والثيران 🐂🐄

تطبيق Android أصلي باللغة العربية مبني باستخدام Kotlin وJetpack Compose.

## المميزات
- واجهة عربية RTL.
- رقم سري من ٤ أرقام مختلفة.
- حساب الأبقار والثيران.
- منع تكرار التخمينات.
- سجل المحاولات وعدّاد النتائج.
- تصميم داكن مناسب للموبايل.

## التشغيل
1. نزّل المستودع أو اختر **Code → Download ZIP**.
2. افتح مجلد المشروع في Android Studio.
3. انتظر انتهاء Gradle Sync.
4. شغّل التطبيق على محاكي أو هاتف Android.

## إنشاء APK
من Android Studio اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
